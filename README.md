## Download

**[Download the latest Sarosa.dmg](https://github.com/nakel-ola/sarosa-releases/releases/latest/download/Sarosa.dmg)** · [All releases](https://github.com/nakel-ola/sarosa-releases/releases)

Requires an Apple silicon Mac running macOS 13 or later. Open the DMG and drag Sarosa into Applications, then press <kbd>⌥</kbd> <kbd>Space</kbd>.

**First launch:** builds aren't notarized by Apple yet, so macOS blocks the first launch. Open **System Settings → Privacy & Security**, scroll down, and click **Open Anyway** next to Sarosa.

Sarosa checks this page for updates and tells you when a new version is out.
